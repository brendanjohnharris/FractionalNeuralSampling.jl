Every exported symbol is documented on the page where it is introduced. The index below links to each of them.

Extensions ​

Three extensions load automatically with their trigger packages:

TriggerProvides
TimeseriesToolsTimeseries(sol) conversion, plus samplingpower and samplingaccuracy for scoring a run against its target
Distances and StatsBaseDivergences between a Density and a set of samples, such as KLDivergence()(𝜋, x)
InterpolationsDensities interpolated from an empirical grid
