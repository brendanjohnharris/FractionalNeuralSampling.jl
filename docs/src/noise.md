# Noise processes

Lévy α-stable noise, compatible with
[DiffEqNoiseProcess.jl](https://github.com/SciML/DiffEqNoiseProcess.jl). `LevyProcess!` is
the in-place form.

```@docs
LevyProcess
LevyProcess!
```

## Linear fractional stable motion

Self-similar α-stable processes with Hurst exponent H, generated by the moving-average
representation.

```@docs
lfsn
lfsm
```
