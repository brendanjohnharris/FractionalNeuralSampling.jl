## Extensions

Three extensions load automatically with their trigger packages:

| Trigger | Provides |
|---|---|
| `TimeseriesTools` | `Timeseries(sol)` conversion, plus [`samplingpower`](@ref) and [`samplingaccuracy`](@ref) for scoring a run against its target |
| `Distances` and `StatsBase` | Divergences between a `Density` and a set of samples, such as `KLDivergence()(𝜋, x)` |
| `Interpolations` | Densities interpolated from an empirical grid |
